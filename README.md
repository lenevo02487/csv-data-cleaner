# csv-data-cleaner

**Messy CSV in → clean, analysis-ready CSV out.** One Python file, zero dependencies.

Every exported CSV has the same problems: stray spaces, blank rows, the header repeated in the middle (from merged monthly files), the same row twice, and dates written five different ways — `2026-01-05`, `05/01/2026`, `5 Jan 2026` — so nothing sorts or filters correctly. This tool fixes all of it in one command and tells you exactly what it changed.

## Quick start (under a minute)

```bash
# no install needed — Python 3.8+ standard library only
python3 csv_cleaner.py sample_messy.csv -o sample_clean.csv --dedupe
```

Output:

```
Cleaned sample_messy.csv -> sample_clean.csv
  Rows in:             25
  Rows out:            20
  Empty rows removed:  2
  Header rows dropped: 1
  Duplicates removed:  2
  Date columns:        order_date
  Dates normalized:    16
```

Run it without `-o` and it writes `<input>_clean.csv` next to your file. Your original file is never modified.

## What it does

- **Trims whitespace** in every cell, header included
- **Removes fully-empty rows** (blank lines, `,,,,` rows)
- **Drops repeated header rows** hiding mid-file
- **Normalizes dates to `YYYY-MM-DD`** — recognizes `DD/MM/YYYY`, `DD-MM-YYYY`, `DD.MM.YYYY`, `YYYY/MM/DD`, `5 Jan 2026`, `Jan 5, 2026` and more. Day-first formats are tried before month-first, which matches most non-US exports. Values it can't parse are left untouched, never guessed.
- **Removes duplicate rows** with `--dedupe` — checked *after* cleaning, so the same row saved with two different date formats is still caught as one duplicate

## Flags

| Flag | What it does | Default |
|---|---|---|
| `input` (positional) | Messy CSV to clean | required |
| `-o`, `--output` | Output file path | `<input>_clean.csv` |
| `--dedupe` | Remove duplicate rows (after cleaning) | off |
| `--date-columns` | Comma-separated date column names, e.g. `--date-columns order_date,signup_date` | auto-detect: headers containing "date" |
